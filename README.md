## Что делает
- Делает серию последовательных запросов (по умолчанию 10) к целевому файлу.
- Обходит кэширование (добавляет временную метку к URL), чтобы замерять реальную сеть, а не локальный кэш.
- Замеряет время каждого запроса и объем переданных данных.
- Считает среднее время ответа и скорость соединения в МБ/с и Мбит/с.

## Требования
- [uv](https://github.com/astral-sh/uv) или Python 3.10+

## Запуск

### Через uv (рекомендуется)
Запуск теста по умолчанию:
```bash
uv run speedtest.py

## Тесты

Тесты написаны с использованием встроенного фреймворка `unittest`:

```bash
uv run python -m unittest test_speedtest.py
